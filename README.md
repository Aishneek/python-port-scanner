## Project Overview

Python Port Scanner is a basic cybersecurity project developed using Python.

It identifies open TCP ports on localhost and authorized private network targets. The project demonstrates fundamental networking and port scanning concepts.

## Features

- TCP port scanning
- Open port detection
- Common service identification
- Custom port range selection
- Target validation
- Scan summary and results
- Lightweight Python implementation

## Technologies Used

- Python 3
- Socket Library
- IP Address Library
- DateTime Library
- Visual Studio Code

1. Install Python 3.

Run the following command:

Enter the target IP address and the port range when prompted.
